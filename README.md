# agent-shell-dashboard

A magit-style dashboard over your [agent-shell](https://github.com/xenodium/agent-shell)
sessions. Rows are grouped by project and laid out as side-by-side
columns; live, awaiting, working and closed sessions all show up
together, and per-row commands let you visit, fork, kill, prompt, or
jump between columns with single-key overlays.

## Installation

Not on MELPA. Clone it and point `load-path` at the clone:

    git clone git@github.com:gempesaw/agent-shell-dashboard.git ~/opt/agent-shell-dashboard

```elisp
(use-package agent-shell-dashboard
  :load-path "~/opt/agent-shell-dashboard"
  :demand t
  :config
  (agent-shell-dashboard-setup))
```

Requires Emacs 28.1 and `agent-shell`.

## Setup is opt-in

The dashboard renders without `agent-shell-dashboard-setup`, but it
installs the advice that captures per-session enrichment. Skip it and
the dashboard degrades rather than breaks: no summaries, no
awaiting-state, no preview line.

## Modules

```
agent-shell-dashboard-data        row sources, persistence, helpers
agent-shell-dashboard-render      cells, columns, refresh, jump
agent-shell-dashboard-commands    mode, keymap, interactive commands
agent-shell-dashboard-tracking    opt-in advice, summary capture
agent-shell-dashboard-transient   ? menu
```

Press `?` in the dashboard for the full key list.

## State files

Tracking persists across restarts. Each path is a defcustom, and all of
them default under `user-emacs-directory` -- worth adding to your
`.gitignore` if that directory is a git repo:

```
agent-shell-dashboard-active-sessions-file    sessions to restore
agent-shell-dashboard-summary-archive-file    generated session summaries
agent-shell-dashboard-forgotten-ids-file      tombstones for dismissed rows
agent-shell-dashboard-marks-file              marked sessions
```

Summaries are generated by prompting the agent itself, every
`agent-shell-dashboard-summary-interval` messages, using
`agent-shell-dashboard-summary-prompt`.

```
make test      # ert suite

make load      # smoke test: require the feature
make clean
```

The Makefile finds its dependencies in `~/.emacs.d/elpa`, picking the
most recently installed copy of each.
